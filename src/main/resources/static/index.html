⚡ Step 1: GitHub Actions Self-Hosted Runner Configuration

  • Runner Directory Setup: Create a dedicated directory (e.g., `actions-runner`) in your local machine.
  • Download Package: Fetch the official runner package from GitHub releases using `curl`.
  • Configure Token: Run `./config.sh --url <repository-url> --token <secret-token>` to link runner.
  • Build & Push: Compiles code, builds Docker images, and updates the manifests repository.

🚀 Step 2: Argo CD & GitOps Prerequisites & Sync

  • Manifests Repository: Centralized tracking of declarative Kubernetes manifests updated by CI.
  • Argo CD Controller: Continuously monitors the repository for any image tag or configuration updates.
  • Automatic Syncing: Detects changes made by GitHub Actions and initiates cluster state synchronization.
  • Health Status Check: Ensures desired state matches the live cluster state seamlessly.

☸️ Step 3: Kubernetes Deployment & Local Components

  • Container Runtime / Docker Desktop: Executes container workloads locally with high performance.
  • Kind (Kubernetes in Docker): Spins up local cluster environments for testing production setups.
  • Namespaces & Resources: Manages pods and services securely inside the `spring-boot` namespace.
  • Live Port Forwarding: Exposes application endpoints to verify dashboard accessibility.
