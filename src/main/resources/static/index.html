⚡ Step 1: GitHub Actions CI/CD & Repository Workflow

  • Self-Hosted Runner Integration: Executes builds locally using your high-performance machine resources.
  • Code Compilation & Testing: Triggers Maven builds and runs unit checks on every code commit.
  • Docker Image Building: Compiles application artifacts into container images and pushes them to Docker Hub.
  • Manifest Update: Automatically updates Kubernetes deployment YAML manifests in the repository.

🚀 Step 2: Argo CD & GitOps Repository Synchronization

  • Declarative State Tracking: Continuously watches the Git repository for newly pushed configuration changes.
  • Automated Syncing: Detects version updates from GitHub Actions without manual intervention.
  • Diff & Compliance Check: Compares desired state in Git with live cluster state to ensure alignment.
  • Trigger Deployment: Passes synchronized manifest templates to the target Kubernetes cluster API.

☸️ Step 3: Kubernetes Deployment & Local Orchestration

  • Cluster Workload Management: Deploys pods and services inside the designated `spring-boot` namespace.
  • Local Container Runtime: Powered by Docker Desktop and Kind (Kubernetes in Docker).
  • Resource Optimization: Manages CPU and memory limits to prevent out-of-memory container terminations.
  • Service Exposure: Enables port-forwarding and stable IP routing for application accessibility.
